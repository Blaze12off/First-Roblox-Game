# Правила работы с проектом

- Репозиторий: https://github.com/Blaze12off/First-Roblox-Game.git.
- После каждого завершённого изменения проекта создавать Git-коммит с понятным описанием. Перед коммитом выполнять проверки, подходящие для изменения; не коммитить секреты и временные файлы.
- Учитывать утверждённые требования из `TEMPLATE_NOTES.md`; новые согласованные правки записывать туда.
- При изменении игры обновлять исходники и соответствующие плейсы согласно текущему процессу сборки. Не считать внешнее изменение файла обновлением открытой вкладки Studio.
- В отчёте разделять локальные тесты, проверку в Studio и реальные облачные проверки; не выдавать шаблоны и неподтверждённые API за работающие системы.
